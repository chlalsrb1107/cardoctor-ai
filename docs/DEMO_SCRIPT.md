# 시연 영상 대본 (약 2분 40초)

에뮬레이터 화면을 녹화하면서 데모 패널로 장면을 바꾼다. 데모 패널은 좌상단 "카닥터 AI"를 길게 누르면 열리고, 녹화 직전에 닫아 둔다. 내레이션은 TTS 음성과 겹치지 않게 앱이 말을 마친 뒤에 넣는다.

| # | 시간 | 화면에서 할 일 | 내레이션 |
| --- | --- | --- | --- |
| 0 | 0:00–0:15 | 정상 화면에서 "전체 점검"을 누르고 진행 바를 보여준다 | 경고등이 켜지면 운전자는 지금 정비소에 가야 할지 모릅니다. 카닥터 AI는 차가 보내는 신호와 지금 상황을 함께 따져 답합니다. |
| 1 | 0:15–0:40 | 데모 패널 → **A 낮·전조등** | 오후 2시, 좌측 전조등이 나갔습니다. 낮이라 1등급, 주말에 점검하면 됩니다. |
| 2 | 0:40–1:05 | 데모 패널 → **B 밤·전조등**. 차량 그림이 빨강으로 바뀌고 음성 경고가 나온다 | 고장은 그대로이고 시간만 밤 9시로 바뀌었습니다. 판정 근거에 "야간 운행 +3"이 붙으며 3등급, 즉시 정비가 됩니다. 같은 고장이라도 상황에 따라 답이 달라집니다. |
| 3 | 1:05–1:25 | "음성 질문"(또는 데모 패널의 "지금 정비소 가야 돼?")을 누른다. 답변이 끝나면 "정비소 안내해줘"를 누른다 | 운전 중에는 화면을 만지지 않고 물어봅니다. 등급과 이유를 음성으로 답하고, "정비소 안내해줘"라고 하면 차량 내비게이션에 바로 목적지가 들어갑니다. |
| 4 | 1:25–1:50 | 데모 패널 → **C 빗길 고속·타이어** → **정차하기** | 빗길 고속도로에서 뒤 오른쪽 공기압이 떨어졌습니다. 비 +2, 고속 +1로 3등급입니다. 차를 세우면 원인·위험·할 일을 자세히 보여줍니다. |
| 5 | 1:50–2:10 | 정차 상태에서 **정비소 사전 리포트(QR)**를 연다 | 정비소에 가기 전에 고장 부위, 등급, 판정 근거, 신호 원값을 QR로 넘깁니다. 견적을 미리 받고 과잉 정비를 막습니다. |
| 6 | 2:10–2:30 | 데모 패널 → 초기화 → **D 서서히 빠지는 공기압** | 고장이 나기 전에도 알려줍니다. 앞 왼쪽 타이어의 공기압 추이를 보면 약 8일 뒤 경고 기준에 닿을 것으로 예측됩니다. |
| 7 | 2:30–2:40 | 데모 패널 → "브레이크 경고" 주입 + 밤 + 비 | 브레이크처럼 안전 핵심 부품은 무조건 3등급 이상이고, 빗길에서는 4등급 즉시 정차와 긴급출동 연결로 바뀝니다. |

마무리 자막: **"경고등은 고장만 알려주지만, 카닥터 AI는 지금 무엇을 해야 하는지 알려준다."** 화면 하단에 Pleos SDK 5종(Vehicle · NaviHelper · TextToSpeech · SpeechToText · FusedLocation)을 표시한다.

## 촬영 전 확인

- [ ] `local.properties`에 `ANTHROPIC_API_KEY`가 있으면 설명 하단에 "AI 설명"이 표시된다. 없으면 "기본 안내 문구"로 나온다. 어느 쪽으로 찍을지 정한다.
- [ ] 긴급출동 번호를 공식 번호로 확인한다(`MainViewModel.ROADSIDE_NUMBER`).
- [ ] 에뮬레이터 언어는 한국어, 볼륨을 켠다(TTS 녹음).
- [ ] 장면 7이 끝나면 데모 패널 → 초기화.
