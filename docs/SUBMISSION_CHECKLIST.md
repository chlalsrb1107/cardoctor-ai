# 1차 제출 체크리스트 (마감 2026-11-15 일 23:59)

공모전 사이트의 제출 안내(/guide/submission)와 FAQ를 기준으로 정리했다. 위에서부터 차례로 확인한다.

## 필수

- [ ] **접수양식(기획서)**: 홈페이지 `/downloads/contest-application-consent.docx`를 받아 작성한다.
  - 본문은 `docs/PROPOSAL_DRAFT.md`에서 옮긴다.
  - 5번 항목(개발 계획)에는 구현 범위와 SDK 5종 활용을 쓴다.
  - `[확인 필요]` 표시는 모두 채우거나 지운다.
- [ ] **서명 동의서**: 팀원 전원(대표자 포함 최대 5명)이 이름, 소속, 연락처, 이메일, 서명, 날짜를 쓴다.
- [ ] **부문 확인**: 팀원 전원이 대학(원)생이면 대학생 부문이고, 한 명이라도 아니면 일반 부문이다. 현대차그룹 임직원이 있으면 수상 대상에서 빠진다.

## 개발 산출물 (가산점)

- [ ] **GitHub 저장소**: 소스와 APK를 같은 저장소에 올린다.
  - [ ] APK는 `apk/팀명_앱이름_release.apk`에 둔다. 지금 파일명은 `apk/팀명_카닥터AI_release.apk`이니 `팀명`을 실제 팀명으로 바꾼다.
  - [ ] 실행 가능한 release 빌드여야 한다. 현재 76MB라 GitHub 일반 업로드 한도(100MB) 안이다.
  - [ ] `local.properties`(API 키)는 올리지 않는다. `.gitignore`에 들어 있다.
  - [ ] README에 필수 항목이 다 있는지 확인한다(현재 모두 있음).
    - 앱 이름과 한 줄 소개
    - 실행 방법
    - 테스트 환경과 설정
    - 에뮬레이터 버전·화면 스펙
    - APK 위치
- [ ] **저장소 공개**: 프라이빗으로 내도 되지만 **11/16(월)까지 Public으로 바꾸고 11/23까지 유지**해야 가산점이 적용된다.
- [ ] **시연 영상**: `docs/DEMO_SCRIPT.md` 순서대로 에뮬레이터 화면을 녹화한다(약 2분 40초).
