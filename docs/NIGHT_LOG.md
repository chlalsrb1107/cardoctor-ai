# 야간 작업 로그 (2026-11-13 04:03 ~ 07:30)

## 원칙

- 에뮬레이터는 설치하지 않는다. 42dot SDK 라이선스 동의는 사용자가 직접 해야 하고, C 드라이브 여유 공간(9.1GB)도 이미지(압축 4.1GB, 설치 후 15GB 이상 예상)보다 부족하다.
- 대신 Robolectric으로 Compose 화면을 PNG로 렌더링해 눈으로 확인하고, 모든 로직은 단위 테스트로 검증한다.
- 빌드 명령(경로에 한글이 있어서 buildRoot를 ASCII 경로로 지정):
  `JAVA_HOME=%LOCALAPPDATA%/cardoctor-toolchain/jdk17 ./gradlew.bat -PbuildRoot=<scratchpad>/cardoctor-build :app:testDebugUnitTest`
- 커밋·푸시는 하지 않는다(사용자 요청 없음).
